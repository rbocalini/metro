# Prototypes — Status Metrô

## Purpose

Contains HTML prototypes built using Google Stitch. These serve as
visual specifications for frontend development.

## Files

- `sao-paulo-rail-status-left-border-accent.html` — Main dashboard
  prototype with left-border accent design for line cards
- `sao-paulo-rail-status-left-border-accent.png` — Screenshot

## Usage

- Open `.html` files directly in a browser to preview the design
- Use as reference for layout, typography, colors, and spacing
- Per Constitution Principle IV, implementations MUST match the
  prototype's layout and behavior intent

## Design Tokens (from prototype)

- Primary color: #003c73
- Background: #F8F9FA
- Surface: #ffffff
- Font: Inter (400, 500, 600, 700, 800)
- Border radius: 0.25rem (default), 0.5rem (lg), 0.75rem (xl)
- Line card: rounded-2xl, border-l-[12px], shadow-sm
